# ПР3 — Свёрточные нейронные сети в задаче биометрии

Практическое занятие № 3 по дисциплине «Технологии искусственного интеллекта в
области безопасности и защиты информации». Двухмерная CNN обучается на наборе
MNIST и используется как простая модель биометрической идентификации: сеть
распознаёт рукописные цифры по изображению 28×28.

## Что делает программа

- загружает MNIST (60 000 обучающих и 10 000 тестовых изображений);
- нормализует пиксели к диапазону 0–1 и переводит метки в One-Hot формат;
- строит CNN: `Conv2D(32) → MaxPooling2D → Conv2D(64) → MaxPooling2D → Flatten → Dense(128) → Dense(10, softmax)`;
- обучает модель 10 эпох (Adam, categorical_crossentropy, batch size 64);
- оценивает точность на тестовой выборке и выводит предсказания для первых пяти образцов.

## Стек

- Python 3.13
- TensorFlow 2.21 / Keras
- NumPy

## Установка

```bash
python -m pip install tensorflow numpy
```

## Запуск

```bash
cd ПР3
python pr3.py
```

Набор MNIST (~11 МБ) скачивается автоматически при первом запуске и кэшируется в
`~/.keras/datasets/mnist.npz`.

## Примечание

Точность может незначительно отличаться при повторном обучении из-за
недетерминированности вычислений на CPU, несмотря на фиксированный сид.
