# ОТЧЁТ по практическому занятию № 4

**Тема:** «Генетические алгоритмы в криптографии (атака на простой шифр)»

## Цель работы

Изучить принципы работы генетических алгоритмов (ГА) и применить их для взлома простого шифра подстановки (шифра Цезаря), используя функцию приспособленности, основанную на частотном анализе текста.

## Порядок выполнения

- Реализация шифра Цезаря (шифрование и дешифрование);
- Создание функции приспособленности, основанной на близости частот букв в расшифрованном тексте к частотам английского языка;
- Реализация основного цикла ГА (инициализация, цикл поколений, селекция, скрещивание, мутация);
- Применение ГА к зашифрованному тексту для нахождения ключа.

## Краткие теоретические сведения

Генетические алгоритмы — класс эвристических методов оптимизации, основанных на механизмах естественного отбора и эволюции. В криптоанализе ГА применяются для поиска ключа шифра в условиях, когда полный перебор невозможен из-за большой размерности пространства ключей. Алгоритм оперирует популяцией потенциальных решений (особей), каждая из которых кодирует возможный ключ.

Основные компоненты ГА: особь (Chromosome) — закодированное решение; функция приспособленности (Fitness Function) — метрика качества решения; селекция — выбор лучших особей для скрещивания; скрещивание (Crossover) — обмен генетической информацией родителей; мутация — случайное изменение гена, поддерживающее разнообразие популяции и предотвращающее преждевременную сходимость к локальному оптимуму.

Шифр Цезаря — шифр подстановки, в котором каждая буква заменяется буквой, стоящей в алфавите на заданном числе позиций (ключ от 1 до 25). Для английского языка известны стандартные частоты букв: самая частая буква «e» (12,70 %), затем «t» (9,06 %), «a» (8,17 %) и т. д. Функция приспособленности расшифровывает текст текущим ключом, считает фактические частоты букв и суммирует их абсолютные отклонения от эталонных. Чем меньше суммарное отклонение, тем ближе текст к естественному языку; для максимизации значение инвертируется: `fitness = 10000 / (S + 10⁻⁶)`.

## Ход работы

Реализован шифр Цезаря для английского алфавита из 26 букв; неалфавитные символы (пробелы, знаки препинания) сохраняются без изменений. В качестве эталона взяты стандартные частоты английских букв.

Исходный текст: «london is the capital of great britain». Он зашифрован ключом 3, получен шифртекст «orqgrq lv wkh fdslwdo ri juhdw eulwdlq». Для атаки использован генетический алгоритм: популяция 100 особей (ключей от 1 до 25), 100 поколений, вероятность мутации 0,1, мутация сдвигает ключ на ±1 в пределах допустимого диапазона. Селекция — отбор лучших 50 % особей, лучший ключ переходит в следующее поколение без изменений (элитизм), остальные потомки получают ключ одного из родителей и подвергаются мутации.
