# ПР4 — Генетический алгоритм для взлома шифра Цезаря

Практическое занятие № 4 по дисциплине «Технологии искусственного интеллекта в
области безопасности и защиты информации». Генетический алгоритм (ГА) ищет ключ
шифра Цезаря по зашифрованному тексту, используя частотный анализ английского
языка вместо полного перебора.

## Что делает программа

- шифрует исходную фразу «london is the capital of great britain» случайным ключом;
- оценивает каждый ключ функцией приспособленности: расшифровывает текст и
  сравнивает частоты букв с эталонными частотами английского языка;
- эволюционно подбирает ключ: популяция 100 особей, 100 поколений, отбор лучших
  50 %, элитизм, мутация со сдвигом ключа на ±1 с вероятностью 0,1;
- выводит найденный ключ, расшифрованный текст и результат проверки.

## Стек

- Python 3.13
- NumPy
- стандартная библиотека (`random`, `string`, `collections`)

## Запуск

```bash
cd ПР4
python pr4.py
```

Программа детерминирована: фиксирован сид `random.seed(404)`, поэтому ключ и
шифртекст одинаковы при каждом запуске.

## Результаты

| Показатель | Значение |
|---|---|
| Истинный ключ | 3 |
| Найденный ключ | 3 |
| Лучшая приспособленность | 195.66 |
| Расшифрованный текст | london is the capital of great britain |
| Ключ найден верно | да |

Оптимальный ключ обнаружен уже в начальной популяции (поколение 0) и сохранялся
дальше благодаря элитизму.

## Примечание

У шифра Цезаря всего 25 ключей, поэтому полный перебор быстрее ГА. Здесь ГА
используется как учебная демонстрация: тот же подход применим к шифрам
подстановки с факториальным пространством ключей, где перебор невозможен.
