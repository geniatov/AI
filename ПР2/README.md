# ОТЧЁТ по практическому занятию № 2

**Тема:** «Однослойный и многослойный персептрон в задаче фильтрации трафика (бинарная классификация)»


## Цель работы

Освоить построение и обучение классических нейронных сетей (MLP) с использованием Keras/TensorFlow для бинарной классификации на основе числовых признаков (имитация сетевого трафика).

## Порядок выполнения

- Генерация синтетического набора данных, имитирующего сетевые метрики (длительность сессии, объём данных, количество ошибок);
- Масштабирование числовых данных (StandardScaler);
- Построение и обучение однослойного персептрона (без скрытых слоёв) и оценка его неспособности решить сложную задачу;
- Построение многослойного персептрона (MLP) и его обучение;
- Сравнение производительности моделей на тестовой выборке.

## Краткие теоретические сведения

Искусственный нейрон вычисляет взвешенную сумму входных сигналов и преобразует её функцией активации: `z = Σ wi·xi + b`, где `b` — смещение. В выходном слое для бинарной классификации применяется сигмоида `σ(z) = 1 / (1 + e^(−z))`, значение которой интерпретируется как вероятность принадлежности к положительному классу. В скрытых слоях используется ReLU: `ReLU(z) = max(0, z)`, вносящая нелинейность и предотвращающая затухание градиента.

Однослойный персептрон содержит только входной и выходной слои и математически эквивалентен линейному классификатору, поэтому разделяет лишь линейно разделимые данные. Многослойный персептрон (MLP) имеет один или несколько скрытых слоёв с нелинейной активацией, что позволяет ему моделировать сложные нелинейные зависимости, характерные для сетевого трафика.

Обучение выполняется методом обратного распространения ошибки: на прямом проходе вычисляется ошибка (бинарная кросс-энтропия), затем градиенты функции потерь по весам распространяются назад по слоям, и веса корректируются оптимизатором Adam в направлении уменьшения ошибки.

## Ход работы

Сформирован синтетический набор данных из 620 образцов с пятью числовыми признаками. Класс Normal (0) описывает нормальный трафик, класс Malicious (1) — вредоносный. Данные классов перекрываются, в них добавлены выбросы (по 10 на класс) и гауссов шум, а в признак № 2 вредоносного класса — нелинейное преобразование, поэтому задача не является линейно разделимой.

Признаки масштабированы StandardScaler, данные разделены на обучающую (70 %) и тестовую (30 %) выборки со стратификацией. Однослойная модель: `Dense(1, sigmoid)`. MLP: `Dense(32, ReLU) → Dropout(0.2) → Dense(16, ReLU) → Dense(1, sigmoid)`. Обе сети обучались 50 эпох с функцией потерь binary_crossentropy и оптимизатором Adam.
