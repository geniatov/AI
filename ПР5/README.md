# ОТЧЁТ по практическому занятию № 5  
**Тема:** «Экспертные системы для выбора оптимального набора средств защиты информации»

## Цель работы

Разработать простую продукционную экспертную систему (на основе правил IF-THEN)
для автоматизированного выбора адекватного набора средств защиты информации
(СЗИ) в зависимости от заданных рисков и типа обрабатываемой информации.

## Порядок выполнения

- определение предметной области: классификация систем по уровню
  конфиденциальности (низкий, средний, высокий);
- формализация базы знаний: словарь правил, связывающих уровень
  конфиденциальности с требуемыми СЗИ (антивирус, межсетевой экран, СОВ, СЗИ НСД);
- реализация механизма вывода (прямой вывод): задание фактов о системе и
  последовательное применение правил;
- вывод результата — рекомендуемого набора средств защиты.

## Краткие теоретические сведения

Экспертная система (ЭС) — компьютерная программа, моделирующая процесс принятия
решений человеком-экспертом в определённой предметной области. В сфере
информационной безопасности ЭС применяются для автоматизированного выбора
оптимального набора СЗИ на основе характеристик защищаемой системы, требований
нормативных документов и выявленных рисков. Они подходят для задач с чётко
формализованными требованиями регуляторов (ФЗ-152, ГОСТы), например для
первичного подбора средств защиты.

Архитектура ЭС включает четыре основных компонента:

- **база знаний** — совокупность продукционных правил вида «ЕСЛИ условие_1 И … И
  условие_n ТО заключение»; условия описывают факты о защищаемой системе,
  заключения — рекомендации по выбору средств защиты;
- **рабочая память** — факты о конкретной ситуации (описание информационной
  системы), на основании которых механизм вывода применяет правила;
- **механизм вывода** — алгоритм применения правил к фактам; использует логику
  прямого (forward chaining) или обратного (backward chaining) вывода;
- **интеллектуальный интерфейс** — взаимодействие с пользователем, в том числе
  объяснение принятых решений.

При прямом выводе система начинает с известных фактов и последовательно применяет
правила, выводя новые факты, пока не достигнет целевого заключения. При обратном
выводе сначала выдвигается гипотеза, затем ищутся правила, заключение которых
совпадает с ней, и проверяются их условия. Для первичного подбора СЗИ удобен
прямой вывод: исходные данные о системе уже известны, требуется получить полный
набор рекомендаций.

Главное преимущество ЭС — способность объяснять принятые решения, что критически
важно при выборе СЗИ для последующей аттестации объектов информатизации. ЭС также
позволяют аккумулировать знания экспертов в формализованном виде. Основные
ограничения — трудоёмкость извлечения знаний, отсутствие самообучения и хрупкость
при выходе за рамки заложенных правил.

## Ход работы

Предметная область — классификация систем по уровню конфиденциальности
обрабатываемой информации. База знаний содержит три набора правил: для низкого,
среднего и высокого уровня. Каждый уровень задаёт обязательные и опциональные
средства защиты.

База знаний экспертной системы:

| Уровень | Обязательные СЗИ | Опциональные СЗИ |
|---|---|---|
| Низкий | Antivirus, Basic_Firewall | Backup_System |
| Средний | Antivirus, NextGen_Firewall, IDS_Monitor | Data_Encryption_Storage |
| Высокий | Antivirus, NextGen_Firewall, IDS_Monitor, TwoFA, System_Audit_Log | Data_Encryption_Storage, Access_Control_System |

В рабочей памяти заданы факты о защищаемой системе: уровень конфиденциальности —
High; система имеет прямой доступ в Интернет; обрабатываются персональные данные;
требования регуляторов — ISO 27001 и GDPR.

Механизм прямого вывода последовательно применяет правила. Сначала по уровню High
добавляются пять обязательных СЗИ. Затем срабатывают дополнительные условия:
доступ в Интернет добавляет шифрование данных при хранении, обработка персональных
данных — систему управления доступом. Наконец, правило усиления при соответствии
GDPR и наличии TwoFA добавляет маскирование данных. Результат формируется как
отсортированный набор уникальных средств, что исключает дублирование рекомендаций.

## Результаты

Экспертная система выбрала 8 средств защиты:

| Средство | Назначение | Основание выбора |
|---|---|---|
| Access_Control_System | Система управления доступом | Опциональное; добавлено из-за обработки ПДн |
| Antivirus | Антивирусная защита | Обязательное для высокого уровня |
| Data_Encryption_Storage | Шифрование данных при хранении | Опциональное; добавлено из-за доступа в Интернет |
| Data_Masking | Маскирование данных | Усиление по требованию GDPR |
| IDS_Monitor | Система обнаружения вторжений | Обязательное для высокого уровня |
| NextGen_Firewall | Межсетевой экран нового поколения | Обязательное для высокого уровня |
| System_Audit_Log | Аудит и журналирование событий | Обязательное для высокого уровня |
| TwoFA | Двухфакторная аутентификация | Обязательное для высокого уровня |

Протокол выполнения программы:

```text
--> ВЫВОД: Усиление безопасности из-за соответствия GDPR.

--- Результат работы Экспертной Системы ---
Проанализированная система: Конфиденциальность=High, Интернет-доступ=True
Требуемый набор СЗИ (на основе правил):
- Access_Control_System
- Antivirus
- Data_Encryption_Storage
- Data_Masking
- IDS_Monitor
- NextGen_Firewall
- System_Audit_Log
- TwoFA
```

## Вывод

Разработана продукционная экспертная система для выбора набора средств защиты
информации. База знаний формализует требования для трёх уровней
конфиденциальности, а механизм прямого вывода применяет правила к фактам о системе
и формирует обоснованный перечень СЗИ. Для заданной системы высокого уровня с
доступом в Интернет, персональными данными и требованиями GDPR выбрано 8 средств,
включая обязательные, дополнительные и усиливающее маскирование данных. Результат
объясним: каждое средство связано с конкретным правилом. Цель работы достигнута.
